
# 공유오피스 체험 고객 결제 전환 예측

## 1. 프로젝트 개요

공유오피스 3일 체험 고객의 방문 및 출입 행동 데이터를 활용하여 유료 결제 전환 여부를 예측하는 머신러닝 프로젝트입니다.

### 프로젝트 목표
- 체험 고객의 결제 전환에 영향을 주는 행동 특성 탐색
- 행동 기반 피처 엔지니어링 및 예측 모델 개발
- 모델 성능 평가 및 예측 오류 분석
- 실무 적용 가능성과 개선 방향 도출

## 2. 데이터

신청, 방문, 출입 및 결제 데이터를 통합하여 분석했습니다.

- 분석 대상: 9,110명
- 결제 전환율: 약 37.6%
- 데이터 분할: Train / Validation / Test

원천 데이터는 공개 저장소에 포함하지 않습니다.

## 3. 분석 프로세스

1. 데이터 통합 및 품질 점검
2. 결측치 및 중복 데이터 처리
3. 탐색적 데이터 분석(EDA)
4. 행동 기반 피처 엔지니어링
5. XGBoost 모델 학습
6. 피처 조합 비교 및 Threshold 검토
7. Test 성능 평가 및 오류 분석

## 4. 주요 분석 결과

### 주요 예측 변수

- 방문일수
- 총출입횟수
- 신청 후 첫 방문까지 걸린 일수

### 최종 모델 성능

| Metric | Test Score |
|--------|-----------:|
| Accuracy | 0.4259 |
| Precision | 0.3878 |
| Recall | 0.9109 |
| F1 Score | 0.5440 |
| ROC-AUC | 0.5862 |

평가 기준: Threshold 0.45

## 5. 핵심 인사이트

- 방문 및 출입 행동을 활용하여 결제 전환을 예측했습니다.
- 높은 Recall을 확보했지만 Precision과 ROC-AUC는 제한적이었습니다.
- False Positive 오류 분석을 통해 모델의 고객 구분 한계를 검토했습니다.
- 실제 서비스 적용 시 예측 성능뿐 아니라 고객 접촉 비용과 운영 목적을 함께 고려해야 합니다.
